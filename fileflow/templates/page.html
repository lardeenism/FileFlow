{% elif page == 'about' %}
MASTER CONCURRENCY

Unlock hardware potential safely.

FileFlow is an I/O-bound teaching system built with a shared queue, native Python worker threads, explicit synchronization, XAMPP MySQL, and confined file storage.

01

Shared memory

Threads in one process share application state. FileFlow protects live worker telemetry with an RLock.

02

Native threads

threading.Thread maps to native threads in CPython. FileFlow records each worker's get_native_id() value.

03

Synchronization

A dedicated Lock serializes duplicate decisions and destination reservation for shared mutable data.

04

I/O concurrency

Disk reads, file movement, and database requests spend time waiting, allowing worker threads to overlap despite the GIL.
